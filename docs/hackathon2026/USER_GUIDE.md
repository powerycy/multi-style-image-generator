# 空间视觉工坊使用手册

## 评委 90 秒体验

1. 打开公网地址，无需登录、无需 API Key。
2. 在“选择起点”中选一个仓库示例，或上传本机 PNG、JPG、WebP；上传文件只在当前浏览器处理。
3. 从 7 种视觉方向中选一个风格，填写场景，再选择轻量、全量或无 UI。
4. 选择输出方式：普通图片、360° 全景或空间景深。
5. 点击“生成空间视觉方案”。
6. 选择 360° 全景时，在右侧画面拖拽查看；选择空间景深时，移动指针查看近似视差。
7. 复制十行结构化提示词，或下载包含素材来源、输出合同和降级方式的 JSON。

## 关键判断

- 360° 模式要求严格 2:1 等距柱状投影，并在提示词中写明左右边缘无缝衔接。
- 普通图片不会冒充全景；它会进入普通图或空间景深路径。
- 公网评委版不会调用付费生图接口，预览来自公开仓库案例或本机上传。
- 公网版的景深是浏览器近似位移，不冒充模型推理；仓库脚本另有 Depth Anything V2 的真实深度路径。

## 数据与隐私

无需账号。上传图片、输入内容和交互状态均留在当前浏览器；刷新后清空。下载的 JSON 会标记素材来源和实际处理方式。

## 测试账号

不需要测试账号、密码或 API Key。
