# 360° 点云漫游

用于“360 点云、全景点云、可以移动的点云场景”。这是全景的相对深度点云；与普通单图浮雕式点云、纯全景贴图预览分开路由。

## 来源与执行

- 已有 2:1 等距柱状投影全景：复用图片和可用深度，不重新生图。比例只是格式条件；还须在球面视角检查前后左右、极点和接缝。
- 普通图片想扩成全环境：先读 [全景流程](panorama-workflow.md)，以该图为参考扩展 360° 全景，保留场景与画风，检查后再转换。不要把普通宽幅图片拉伸成“全景”。用户只让移动已有点云或明确不要生图时，先复用已有资料，不擅自生成新场景。
- 无底图：按用户指定画风生成并检查全景，再转换。

在 Skill 目录运行：

```bash
python3 scripts/run_with_deps.py create_panorama_pointcloud.py <panorama.png> --out-dir <directory>
```

默认实际推理 Depth Anything V2 Small；已有稳定深度加 `--depth <stable.png>`，已有 raw 加 `--raw-depth <raw.png>`。两者互斥。复用时分别标记 `supplied-stable-depth` / `supplied-raw-depth`，不声称本次重新推理。失败报告，不静默降级。输入深度与全景尺寸必须一致。

## 场景补全与移动

默认 `--completion none` 只重投影全景深度，不添加隐藏表面。用户明确要求扩大成完整可移动场景时，可以使用近似补全，但应准确说明可见资料的边界。

对于有地面、岩壁的室外场景，可使用：

```bash
python3 scripts/run_with_deps.py create_panorama_pointcloud.py <panorama.png> \
  --depth <stable.png> --completion terrain --movement-range 95 --speed 4 \
  --title "360° 点云漫游" --out-dir <directory>
```

`terrain` 延伸地面并给高深度表面添加粗略岩石体积，颜色取自现有图。它是室外近似补全，不能用于任意室内、悬空场景或代替建筑建模；看不到的建筑内部、背面没有被真实恢复。不要把“点更多”说成“完整 3D”。若用户要求准确结构，应说明需要多视角资料或原始三维资产。

参数：`--rows 128..1000` 默认 720；`--movement-range` 为相对场景单位，非米；`--speed 1..12`；`--yaw` / `--pitch` 设置初始视向。移动范围默认无补全 20、地形补全 95。扩大范围不会自动恢复遮挡内容，远离初始视点可能出现拉伸、缺口和穿插；依据实际多位置预览调节，不能仅测试原点。

## 交互与交付

HTML 自包含、离线可开。手动水平与垂直 360° 旋转，滚轮缩放，WASD 移动，Q/E 升降，Shift 加速；手机有按住移动按钮，点大小与速度滑杆。松手停止，保存视角和位置，不加入自动演示或重置。保存按图片内容与补全模式隔离，避免不同场景串用位置。

交付 HTML、PLY、稳定深度和 JSON 来源报告；推理或复用 raw 时也给出 raw。PLY 含 XYZ、RGB、`source_kind`：0 为全景深度表面，1 为近似岩壁，2 为扩展地面。

验证实际生成入口：检查桌面/手机显示、超出旧位置的移动、停止与刷新保持、六个方向和多个位置、接缝、控制条边界及页面错误；核对 PLY 点数和有限坐标。发现补全遮挡原结构或明显穿插时先调整，不把程序无报错当作视觉合格。
